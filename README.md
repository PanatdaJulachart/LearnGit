# LearnGit
สวัสดีค่ะ นี้เป็นครั้งแรกที่ได้ศึกษาการใช้ Github 15-02-68
ตอนนี้กำลังศึกษาอยู่ที่มหาวิทยาลัยรามคำแหง สาขาวิทยาการคอมพิวเตอร์
ปี 1 เทอม 2 รู้สึกเรายังทำได้ไม่ค่อยดี อยากพยายามให้มากกว่านี้
ความใฝ่ฝัน และแรงบัลดาลใจในการเรียนสาขาวิชานี้ คือ
เราอยากให้CODE ช่วยเหลือคนอื่นได้ค่ะ ไม่ทางใดก็ทางหนึ่ง

ที่คิดๆไว้ตอนนี้ อยากจะทำ Project 
1. เว็บไซต์ที่มี workshop เล็กๆ ที่เชื่อมความสัมพันธ์ทุกคู่ความสัมพันธ์
2. ด้ารการศึกษา ที่คิดๆไว้เรื่องของศาสนาพุทธก็น่าสนใจ
เพราะเรามีเพรชเม็ดงามที่เข้าใจในเรื่องนี้ดีกว่าเรา เป็นคนที่เก่งมากๆ ดีใจที่เขามาอยู่ในทีมเรา (แฟนเราเอง อิอิ)
3. เครื่องมือที่ช่วยเหลือผู้พิการ ช่วยให้ชีวิตของพวกเขาง่ายขึ้น 

ทั้งหมดที่จะทำไม่อยากเอากำไรใดๆ หรือผลประโยชน์ รวมถึงชื่อเสียง
เราทำเพราะอยากจะส่งต่อความรักให้แก่ผู้คนบนโลก
เหมือนที่เราได้รับมา
เปรียบดังโอ่งน้ำที่ล้นออกมา จนเราอยากจะแบ่งให้กับโอ่งอื่นๆ

นี้คือความมุ่งมั่นแรงกล้าที่ทำให้เรามีกำลังสู้ต่อไป
หวังว่าสักวันหนึ่งเราจะเป็น ผีเสือตัวเล็กๆ ที่ขยับปีกโบยบิน ด้วยความอ่อนโยน
สร้างอะไรที่เป็นประโยชน์ได้จริงแก่ผู้คนบนโลกใบนี้

และที่สำคัญ อยากขอบคุณ แซม ผู้ที่ชักชวนและผลักดันฉันไปในทางที่ขึ้น
ความคิดเหล่านี้จะไม่เกิดขึ้นเลย "ถ้าไม่มีคุณ"
ผู้เป็นกัลยณมิตรของฉัน ขอบคุณอย่างใจจริง.
